# Security Policy

## Supported versions

This project does not currently maintain a formal version matrix. Security fixes are handled on the latest main branch unless otherwise noted.

## Reporting a vulnerability

Please do not open a public issue for security-sensitive bugs.

Instead, report them privately by emailing the maintainer or using the repository's private reporting channel if one is configured.

Please include:

- a description of the vulnerability
- steps to reproduce it
- the affected component or file
- the impact and severity
- any suggested remediation

## Disclosure expectations

We ask that reporters allow a reasonable amount of time for triage and remediation before public disclosure.

If a fix is required, we will coordinate on a responsible disclosure timeline.
